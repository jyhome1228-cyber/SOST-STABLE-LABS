01

PROJECT OVERVIEW

브랜드 연구소의 철학과 프로젝트를 하나의 편집 시스템으로 정리하고, 콘텐츠 아카이브와 실제 운영 기능까지 연결한 웹 플랫폼입니다.

02

PLATFORM STRUCTURE

Research에서 Portfolio,
운영 영역까지 하나의 구조로 연결했습니다.

01 / BRAND

Home · About
브랜드 철학과 연구소의 관점을 정리

02 / RESEARCH

Research
브랜드 연구와 방법론을 콘텐츠화

03 / ARCHIVE

Portfolio · Journal
프로젝트와 기록이 계속 축적되는 구조

04 / OPERATION

Client · Admin
공개 콘텐츠와 운영 기능을 분리

03

BRAND EXPERIENCE

결과물보다 먼저,
BDLAB의 사고방식이 읽히도록 설계했습니다.

EDITORIAL SYSTEM

Research-led structure

BDLAB은 브랜드를 로고나 이미지로만 보지 않고 제품, 서비스, 공간, 콘텐츠와 사용자 경험이 함께 작동하는 시스템으로 바라봅니다. 이 관점이 웹에서도 단계적으로 이해되도록 Home, About, Philosophy, Research Flow의 콘텐츠 위계를 정리했습니다.

VISUAL LANGUAGE

Content over decoration

강한 장식보다 타이포그래피, 여백과 이미지의 리듬을 중심으로 브랜드 디자인 연구소의 태도를 드러냈습니다. Research와 Portfolio가 서로 다른 콘텐츠이면서도 동일한 시각 체계 안에서 이어지도록 구성했습니다.

04

DEVELOPMENT SYSTEM

가볍게 배포하고,
필요한 운영 기능은 데이터로 연결했습니다.

FRONTEND / DEPLOY

HTML · CSS · JavaScript

콘텐츠 중심의 반응형 프런트엔드를 구성하고 GitHub Pages를 통해 bdLab.me 커스텀 도메인으로 배포하는 단순한 운영 흐름을 만들었습니다.

DATA / OPERATION

Firebase · Firestore

공개 사이트와 별개로 Client, Admin 등 데이터가 필요한 운영 영역을 분리하고 Firebase 기반 기능이 확장될 수 있는 구조로 준비했습니다.
