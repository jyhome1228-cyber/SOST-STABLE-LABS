# SOST STABLE LABS

Stable Systems for Better Business.

기업의 웹사이트, 커머스, 고객관리와 업무 운영체계를 안정적인 디지털 시스템으로 구축하는 SOST STABLE LABS의 공식 웹사이트입니다.

## Structure

```text
SOST-STABLE-LABS/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
└─ assets/
   └─ favicon.svg
```

## Local Preview

저장소를 내려받은 뒤 `index.html`을 열거나 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.
