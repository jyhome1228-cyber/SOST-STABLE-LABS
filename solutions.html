SOLUTIONS / 14 SERVICES

기업에 필요한 디지털 환경을
하나의 구조로 구축합니다.

홈페이지 한 페이지부터 CRM과 사내 운영체계까지, 기업의 현재 상황과 우선순위에 맞춰 필요한 범위를 조합합니다. 모든 솔루션은 기획, 디자인, 퍼블리싱과 개발을 연결해 제공합니다.

14 SOLUTIONS
01

WEB

기업 홈페이지 구축

기업과 브랜드의 정보 구조를 정리하고 반응형 웹사이트로 구축합니다.

  • 기업·브랜드 사이트
  • 다국어·채용·랜딩페이지
  • 콘텐츠 관리 기능
02

PLATFORM

웹서비스·플랫폼 개발

회원, 콘텐츠, 신청과 검색 기능을 포함한 웹 기반 서비스를 개발합니다.

  • 회원가입·로그인
  • 마이페이지·권한 관리
  • 콘텐츠·커뮤니티 플랫폼
03

CRM

CRM 고객관리 시스템

문의부터 상담, 계약과 후속 일정까지 고객 정보를 체계적으로 관리합니다.

  • 고객·상담 이력
  • 담당자·영업 단계
  • 계약·후속 일정 관리
04

WORK

프로젝트·업무관리

고객사별 프로젝트, 일정과 담당 업무를 하나의 화면에서 관리합니다.

  • 프로젝트·업무 배정
  • 캘린더·우선순위
  • 파일·요청사항 관리
05

OPERATION

기업 내부 운영 시스템

조직에 필요한 공지, 일정, 자료와 협업 흐름을 맞춤형으로 구축합니다.

  • 직원·부서·권한
  • 공지·자료·회의
  • 외주·협력업체 관리
06

ADMIN

관리자 페이지 개발

운영자가 직접 콘텐츠와 회원, 문의 데이터를 관리할 수 있도록 설계합니다.

  • 콘텐츠·배너·팝업
  • 회원·문의·예약
  • 권한·활동 기록
07

BOOKING

예약·접수 시스템

서비스와 공간, 상담에 필요한 날짜와 인원 기반 예약 흐름을 구축합니다.

  • 시간·인원·옵션
  • 승인·취소·변경
  • 안내 메시지·통계
08

CAFE24

카페24 쇼핑몰 구축

카페24의 주문과 결제 기능을 기반으로 브랜드 맞춤 쇼핑몰을 구축합니다.

  • 신규 구축·리뉴얼
  • 메인·목록·상세 디자인
  • 상품·옵션·배송 설정
09

COMMERCE UI

카페24 기능 커스텀

상품 진열과 옵션 선택, 모바일 구매 동선을 코드 기반으로 개선합니다.

  • 맞춤 상품 진열
  • 옵션·구매 UI
  • 브랜드관·기획전
10

DATA

데이터 대시보드

고객, 문의, 예약과 프로젝트 현황을 한눈에 확인할 수 있도록 시각화합니다.

  • 기간별 통계·차트
  • 검색·조건 필터
  • 엑셀·CSV 다운로드
11

INTEGRATION

외부 서비스·API 연동

분리된 서비스와 데이터를 연결해 업무가 하나의 흐름으로 이어지게 합니다.

  • Firebase·Google
  • 지도·결제·공공데이터
  • 알림톡·채널톡·분석

문의 등록, 담당자 알림과 반복적인 데이터 정리를 자동화합니다.

  • 문의·예약 자동 등록
  • 상태·마감 알림
  • 데이터·통계 자동 집계

기존 플랫폼과 노후 코드를 분석해 관리하기 쉬운 구조로 재구축합니다.

  • 코드·속도 최적화
